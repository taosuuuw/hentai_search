# EroMeta · 绅士聚合搜索

纯前端（HTML/CSS/JS，零依赖、零构建）的成人向同人志**元数据聚合搜索界面**，
外加一个**零依赖的本地网关**（`tools/gateway.js`，只用 Node 内置模块）用来打通中文源的官方 API。

```yaml
# 批注头部（由维护者在 1.0 分支首版补充）
project:    EroMeta · 绅士聚合搜索
owner:      taosuuuw
repository: https://github.com/taosuuuw/hentai_search
branch:     1.0
entry:      index.html          # 唯一入口；scripts 传统顺序加载，非 ES Module
runtime:    浏览器静态页面 + 可选 Node 本地网关（tools/gateway.js，零依赖）
build:      无。零依赖、零构建
license:    未声明（见文末「已知限制」的许可证批注）
```

> ⚠️ 本项目不托管、不缓存、不代理任何图片或作品文件，只是把公开第三方站点的检索结果聚合到一个界面里。

## 快速开始（两种模式）

### 模式 A：带本地网关（推荐，中文源才能真的检索）

```bash
node tools/gateway.js
# 然后用浏览器打开 http://127.0.0.1:8788/
```

网关同时充当静态服务器，所以页面与接口**同源**，连跨域都省了。
启动后页面会在 1 秒内自动识别到它（抽屉最下方「本地网关」会显示 `✓ 已连接`），
并自动启用「拷贝漫画」，禁漫天堂也会自动切到官方 APP API。

可选参数：

```bash
node tools/gateway.js --port 9000
node tools/gateway.js --picacg-email you@example.com --picacg-password ****   # 启用哔咔检索
set PICACG_TOKEN=xxxx && node tools/gateway.js                                # 或直接用现成 token
```

> <details>
> <summary>📌 批注：纯前端模式的真实边界（3 条）</summary>
>
> 【风险】纯前端模式下浏览器会直接请求第三方接口，MangaDex / Danbooru / nhentai 等源的成功率取决于对方 CORS 头与公共代理可用性；这三者都是随时可能变化的外部条件。
> 【已核对】用 HTTP 打开优于 file:// 的原因是 file:// 的 Origin 为 null，部分公共代理会直接拒绝，与文末「建议用 HTTP 打开」的结论一致。
> 【已核对】成年人确认页存在，确认状态为本地持久化（assets/js/core.js 的持久化工具）。
>
> </details>

### 模式 B：纯前端

```bash
python -m http.server 8777      # 或直接双击 index.html（file:// 也可用，但部分公共代理会拒绝 null Origin）
# 访问 http://127.0.0.1:8777/
```

没有网关时，禁漫天堂退化为「镜像站 HTML 检索」，拷贝漫画/哔咔不可用。

首次进入会有一个成年人确认页；确认后进入主界面。

> <summary>📌 批注：网关存在的理由与职责边界（2 条）</summary>
>
> 【已核对】网关承担的三件事正是浏览器做不到的：① 转发自定义请求头（自定义头会触发 CORS 预检，而公共代理不转发请求头）② Node 内置 crypto 计算 MD5 ③ AES-256-ECB 解密。三者都在 tools/gateway.js 内实现。
> 【风险】README 未声明网关的监听地址是否可被外部访问。/api/proxy 是通用中转、不限制目标域名，若把网关暴露到非回环地址，等于对外提供了一个开放代理，发布前须确认。
>
> </details>

## 为什么需要那个本地网关

禁漫天堂、哔咔、拷贝漫画的官方 API 都有两个共同点：**必须带自定义请求头**（`token` / `signature` / `Host` / …），
**响应还经常是 AES 加密的**。这两点浏览器都做不到：

- 自定义请求头会触发 CORS 预检，而公共 CORS 代理不转发请求头，站点也不会回 `Access-Control-Allow-Origin`；
- 浏览器里没有 MD5（JM 的 token 与 AES 密钥都基于 `md5(时间戳+密钥)`），也没有 ECB 模式的 AES。

调研了两个现役实现（`ComicSparks/jasmine`、`venera-app/venera`）后发现它们能直连**不是因为找到了什么巧办法**，
而是因为**它们都是原生客户端**：jasmine 的 HTTP 全部在 Rust 层用 FFI 发出（Dart 层连 `dio`/`http` 都没装），
venera 走 `dio` + `rhttp` 原生 socket —— 原生环境压根没有同源策略。两者都没有用任何第三方聚合 API。

所以本项目采用同样的思路，只是把「原生层」换成一个**本机 Node 进程**：
签名、解密、取页面都在网关里完成，浏览器只跟 `127.0.0.1` 说话。

网关实现的关键算法全部来自上述两个仓库的现役源码：

| 源 | 网关做的事 |
| --- | --- |
| **禁漫天堂** | 启动时拉取社区维护的**实时域名列表**（base64 + AES-256-ECB，密钥 `md5("diosfjckwpqpdfjkvnqQjsik")`，来自 `venera-configs/jm.js`），失败再退回内置域名；请求带 `token = md5(时间戳 + "18comicAPPContent")`、`tokenparam`、`X-Requested-With`、Android UA；响应按 `AES-256-ECB`、密钥 `md5(时间戳 + "185Hcomic3PAPP7R")` 解密；`/setting` 还会下发图片 CDN 域名 |
| **拷贝漫画** | 从 `api.copy-manga.com/api/v3/system/network2` **动态发现 API 节点**，再带上 `x-auth-timestamp` + `x-auth-signature`（HMAC-SHA256，密钥为 base64 常量）`umstring`/`source: copyApp` 等头；节点失败会在多个候选节点间重试 |
| **哔咔** | 请求签名 `HMAC-SHA256(key, lowercase(path + time + nonce + METHOD + apiKey))`，`api-key` / `nonce` / `time` / `signature` / `app-version` / `okhttp/3.8.1` 全套头；搜索走 `POST /comics/advanced-search?page=N`；`authorization` 来自 `POST /auth/sign-in`（网关可用 `--picacg-email/--picacg-password` 代登录，或读 `PICACG_TOKEN`） |
| **任意站点** | `/api/proxy?url=` 通用中转（自动补 `Referer` 与浏览器 UA），给 wnacg / hitomi / 自定义源这类 HTML 源用；取不到的域名会进 45s 冷却 |

> <details>
> <summary>📌 批注：网关算法与常量（3 条）</summary>

> 【已核对·禁漫】签名与解密常量确在 tools/gateway.js：token = md5(时间戳 + "18comicAPPContent")、响应按 AES-256-ECB 密钥 md5(时间戳 + "185Hcomic3PAPP7R") 解密；域名密钥数组以 "diosfjckwpqpdfjkvnqQjsik" 为主密钥，另有一个备用变体。

│  └──────────────────────────────────┘ │

│  网络提醒（仅在需要开 VPN 时出现）      │
│  检索思维链（仅检索时出现，紧贴搜索框，折叠成一行）│
│  结果卡片（紧跟其下）                 │
└─────────────────────────────────────┘

- **抽屉从搜索框顶部向上展开**：滑块与拉手条贴在搜索框**上沿**，按住**向上拉**面板就从搜索框顶部往上升，
  同时搜索框本身向下让位（最多 17vh），所以面板总有地方可展开，顶边会一直升到距视口顶部约 10px。
  拖到一半松手停在那个高度，两端自动吸附；滑块本体随高度上下移动并高亮。
  拉手文案跟着变（`向上拉出筛选` → `继续上拉展开` → `下拉收起筛选`）。
  点面板与搜索框以外的地方会自动收起。`Esc` 也收起。
  键盘可达：滑块聚焦后 `↑/↓` 微调、`Home/End` 全开全关、`Enter` 切换。
- **思维链贴着搜索框底部**：总高约 60px，折叠态只显示**一行清晰的当前步骤**
  （例如 `✓ 禁漫天堂 返回 12 条（3.33s）`），更早的行以 `blur(2.6px)` 模糊退场并滚出可视区；
  展开后所有行都恢复清晰可读。点击表头展开/收起。

## 功能对照

### 1｜取消内容分级，改为 R18G / AI 筛选

- 原来的「全年龄 / 暗示 / 情色 / 成人」分级控件**已整体移除**。MangaDex 源固定请求 `suggestive / erotica / pornographic`。
- 新增 **猎奇 / R18G** 与 **AI 绘画** 两个三段式开关：`不限 / 只看 / 排除`。
- 双路生效：源站支持就在服务端拼标签；所有源返回的条目都会按内置词表（`NS.GORE_TAGS` / `NS.AI_TAGS`）本地兜底打标后再过滤。

### 2｜单搜索框 + 上拉抽屉

语言等选项全部收进搜索框上方的抽屉，由独立的垂直滑块拉出（见上）。

### 3｜思维链：常态不显示 / 折叠 + 模糊 / 点击展开

- 不检索时整个面板 `hidden`，页面上完全看不到。
- 开始检索才出现，**初始状态折叠**：表头 + 一行当前步骤。
- 那一行清晰可读，更早的行做 `blur(2.6px)` + 淡出**动画**退场；新行以 `blur(4px) → 0` 聚焦。展开后全部清晰。

### 4｜结果紧跟搜索框下方

DOM 顺序即视觉顺序：网络提醒 → 搜索框 → 思维链 → 结果网格。网络提醒在搜索框**上方**，
思维链压到约 60px 高，所以结果始终紧贴搜索框。

| **紳士漫畫**（wnacg） | HTML | 10 个内置域名并行竞速（取自 `ComicSparks/wax` 与 `venera-configs/wnacg.js` 的现役列表）；关键词走 `/search/?q=&f=_all&s=create_time_DESC&syn=yes` 与 `/albums-index-tag-*` 双路径并合并去重；解析 `.gallary_item` 并兜底扫 `photos-index-aid-*` |

**域名轮换怎么办？** 这类站点几个月就换一次域名，任何硬编码列表都会过期。四层兜底：

1. **实时域名列表**（禁漫，网关内置）：来自社区维护的 `newsvr-2025.txt`，base64 + AES 解出当前 `Server[]`。
2. **镜像域名输入框**（抽屉内）：禁漫 / 紳士各自的域名池可直接追加，逗号分隔，立即生效。
3. **自定义中文源**（抽屉内）：填「名称 + 域名 + 解析模板」新增一个源，内置四个社区同款模板
   （喵绅士 `/search?keyword=`+`.mh-item`、紳士 `/search/?q=`、禁漫 `/albums?screen=`、通用自动识别）。
4. **网关通用代理**：`/api/proxy` 带正确的 `Referer`/UA 取页面，失败的域名 45s 冷却。

**取源顺序**：本地网关 → 会话内记住的可用公共代理 → 其余公共代理 → 直连。

`可以连通，但被浏览器跨域策略拦截…` 或 `完全不可达（可能被网络限制或被墙）…`，
并在没有网关时提示启动 `node tools/gateway.js`。

> **建议用 HTTP 打开而不是双击 file://**。`file://` 页面的 `Origin` 是 `null`，一部分公共代理会直接拒绝。
