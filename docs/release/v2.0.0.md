**发布日期**：2026-09-20

## 这一版的重点：站内在线阅读

搜索结果里点开卡片的等比放大视图，即可**直接在站内阅读**，不必再跳回原站翻页
（新增 `assets/js/reader.js` + 网关 `/api/reader`）。

**支持的源（10 个）**：MangaDex / nhentai / Danbooru / 紳士漫畫（wnacg）/ E-Hentai / Hitomi /
Pixiv / 拷贝漫画 / 禁漫天堂 / porn-comic。页地址由网关统一转成 `/api/proxy?...` 并带上正确的
`Referer`，浏览器不会撞 `i.pximg.net` 等图床的防盗链。

| 能力 | 说明 |
| --- | --- |
| 两种阅读方向 | 上下连续滚动（默认）/ 左右单页；滚轮、`←/→`、点左 / 右半屏都能翻页 |
| 章节 | 多章作品（MangaDex / 拷贝漫画）有章节下拉；单章作品自动隐藏下拉 |
| 自动连读 | 滚到章末自动接上下一章，并提前预取下一章 |
| 缩放 | 50%–300%，步进 20%（`Ctrl`/`⌘` + `+` / `-` / `0`） |
| 键盘 | `Esc` 关闭 · `←/→` 翻页 · `Home/End` 首末页 · `Ctrl +/−` 缩放 |
| 断图自愈 | 同一页带备用地址（目前只有 MangaDex 有 `alt`）时，加载失败会自动换图床重试一次 |

- **禁漫的图片是分块打乱的**：网关从章节页模板读到 `scramble_id` 并按站点自己的算法算好分块，
  前端用 canvas 还原；**拿不到 `scramble_id` 就按原图显示**——宁可不动，也不乱动。
- **porn-comic 的正文图不经 Cloudflare**（只有条目页需要过），所以阅读比检索顺利。

## 其它变更

- **一键启动器**：新增 `start-engine.cmd` + `tools/start-gateway.ps1`。
  停掉占用端口的旧引擎 → 用当前代码起新引擎 → 等就绪 → 真打一遍 `/api/ping` 与 `/api/reader` 自检 → 打开浏览器。
  支持 `-Status` / `-Stop` / `-Port` / `-NoBrowser` / `-Foreground` / `-KeepOpen`。
  启动器只终结**占用该端口的 node 进程**，其它进程一律不碰。
- **网关大幅扩展**（`tools/gateway.js`，+1907 行）：新增 `/api/reader` 与 `/api/ping`，
  实现 E-Hentai（逐页 N+1，限速 1300ms、单次最多 40 页、结果缓存 4 分钟）、Hitomi（图集数据取自 CDN）、
  Pixiv（`/ajax/illust/<id>/pages`，**不需要登录 cookie**）、拷贝漫画（官方 APP API，code 210 退避重试）、
  禁漫（`/chapter` + `/chapter_view_template`）与 porn-comic 的取页。
- **前端集成**：`results.js`（+518）、`style.css`（+594）、`sources.js`（+358）配合阅读器与放大视图。
- **README 同步至 2.0**，批注增至 50 条。

## 已知问题与注意事项

- **阅读功能强依赖本地网关**：无网关时阅读器会明确报「需要本机网关」，而不是静默空白。
  「能搜不能读」请先查网关是否在跑、是否成功接上了系统代理。
- **E-Hentai 搜索**：在当前出口 IP 下上游搜索一律返回空集，网关会如实说明并退到
  `/torrents.php?search=` 兜底。这不是本版的回归，是站点侧行为。
- **文档修正**：README 信息源表原写「Kemono 默认 开」，与代码不符——
  `assets/js/core.js` 的默认源列表并不含 `kemono`，且只有拷贝漫画有「网关在线自动开」逻辑
  （`assets/js/app.js`）。本版已把该格改为「关（需在信息源里手动勾选）」，代码行为未改动。
- **未加入 `.gitattributes`**：仓库 `core.autocrlf=true`，在 Windows 上 clone 后
  git 会提示行尾将被改写（LF→CRLF）。这是文本仓库的既有卫生问题，尚未在本版处理。
- **哔咔已移除**：前端无该源与登录入口；网关侧 `/api/picacg/*` 仍保留但无调用点。
